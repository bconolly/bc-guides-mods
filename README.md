# bc-guides-mods
Helpful mods for Claude

## Mods

- [sidegigs-tracker](mods/sidegigs-tracker): a pane beside the chat listing project files (by folder, with sizes) and published artifacts.

Install:

```
/plugin marketplace add bconolly/bc-guides-mods
/plugin install sidegigs-tracker@bc-guides-mods
```

## About BC Guides

These mods come from BC Guides, practical guides for high-performing teams. Get the guides on Payhip: [Beyond vibe coding](https://payhip.com/b/DglMp).
